# Al-Syed Jalal AI V32 — Enterprise Data Core

V32 is the next stage after V31 Live Production Integration. It upgrades persistence from a JSON file to PostgreSQL and adds database-backed sessions, role enforcement, indexes, audit events and Docker Compose setup.

**Frontend:** `frontend/` — GitHub Pages-compatible static app.
**Backend:** `backend/` — Node 20+ API with PostgreSQL.
**Docs:** `docs/ARCHITECTURE-V32.md`.

Important: deploy the backend over HTTPS and change all default secrets/passwords before real use.
