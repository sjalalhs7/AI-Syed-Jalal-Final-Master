# V35 Security Checklist

- [ ] HTTPS enabled for the API
- [ ] CORS restricted to the real frontend origin
- [ ] Production admin password changed
- [ ] Secrets stored outside source control
- [ ] Database is not publicly exposed
- [ ] Backups encrypted and access-controlled
- [ ] Restore test completed
- [ ] Session TTL reviewed
- [ ] Login throttling monitored
- [ ] Audit events retained according to policy
- [ ] Error logs monitored without leaking passwords/tokens
- [ ] GitHub Pages repository contains no production secrets or private data
