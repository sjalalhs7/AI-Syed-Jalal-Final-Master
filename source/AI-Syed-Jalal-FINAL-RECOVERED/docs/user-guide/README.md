# User Guide

The primary data-entry workflow is designed for PC/laptop use, with responsive support for mobile screens.

Core workflow:

1. Sign in.
2. Open a Region.
3. Select a Sector.
4. Add or edit records.
5. Import/export data when required.
6. Generate Guard and Police Verification documents.
7. Use print preview controls before physical printing when available.

For shared multi-PC operation, use the deployed backend and PostgreSQL rather than treating browser-local storage as the shared system of record.
