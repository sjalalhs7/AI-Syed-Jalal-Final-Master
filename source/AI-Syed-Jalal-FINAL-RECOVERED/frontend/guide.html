Use the workspace

  1. Data Vault: search shared records; authorized writers can add, edit and import them.
  2. Document Studio: write a general document, download the text, or print / save as PDF. Drafts are not saved automatically.
  3. AI Command: use Local tools now; choose Cloud AI only when configured.
  4. Settings: change theme, password and other sessions.
  5. Admin: user management, diagnostics, backup and confirmed merge restore.

Use JARVIS voice

  1. Open JARVIS and sign in or start the local preview.
  2. Choose a speech language and response engine. A provider with a configured key is selected for AI chat when available, but must still respond successfully; otherwise Agent mode handles limited tools. An optional setting sends recent cloud exchanges for follow-up questions.
  3. Press Start conversation and allow microphone access. Each final transcript is sent, the reply is read aloud, and listening resumes; press Stop to end it.
  4. For a single reviewed transcript, use Dictate once instead. Tap Interrupt & speak during a spoken reply, or type. Send or clear an existing draft before starting a continuous voice conversation.
  5. Tasks and notes need your explicit confirmation. Cloud requests may incur provider charges; a configured key does not prove it works.

Your browser’s speech service may process audio online. Voice support and Urdu availability vary by device; there is no background wake word.

Website hosting, cloud AI and external services

GitHub Pages is a static website preview. It can show the pages, but it cannot run the login API, database or server-side AI. For real sign-in and saved data, open the secure application server (Cloudflare Pages + Neon) or run the local preview with npm ci and npm run dev. The banner links to setup options.

Local tools work now. Open-ended cloud answers need a server-side provider key and a successful live provider request. Configure keys only in your hosting provider’s secret settings—never paste them into chat or frontend files. See the current status and database safety guidance before any repair.

Not connected: OpenJarvis desktop control, Gmail/Calendar, contacts, WhatsApp, scheduled briefings, purchases or autonomous external actions. The app will not pretend to perform them.

Agent Lab (agent-lab.html): runs a graded self-check against the live application — API, database, security boundaries, agent behaviour, honesty labels, the 3,500-skill library and the page inventory — and stores the evidence per account. A passing run is evidence about this deployment, not a production certificate.

Premium ElevenLabs voice is separate from browser speech and is not enabled by default.

If something does not work

  • “Sign in”: open JalalAi and use “Try the local preview”, or sign in with your account.
  • Microphone blocked: allow microphone permission in browser/site settings, or type instead.
  • Cloud unavailable: use Local tools; the owner must configure and verify the provider.
  • Old screen after an update: reload once. Private pages and API responses are not cached.
  • Production use: do not use the shared preview for real data. Review the current status, verify a full backup and rehearse on an isolated target before any database repair.
