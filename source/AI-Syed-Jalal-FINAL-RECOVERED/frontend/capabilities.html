Try each one

  • ShortcutsInstall the app, then right-click (or long-press) its icon for New note, Start here, Workspace and Arena.
  • File handlingIn your OS file manager, choose “Open with” for a .txt or .md file and pick this app. The text lands in Quick Notes.
  • Launch handlerWith the app open, launching it again focuses the existing window instead of stacking a second one.
  • Protocol handlingAfter choosing this app as the handler, opening a web+ajalal:// link lands on the link review page.
  • Share targetOn Android or ChromeOS, share text from another app and pick this app; it opens the share page.
  • WidgetOn Windows 11, add the New note widget from the widgets board.
  • Note takingOn ChromeOS, “New note” from the stylus tools or context menu opens a blank Quick Notes.
  • Window controls overlayDesktop installs draw the header into the title bar area; the drag region is real, not a picture of one.
  • Tabbed displayChromeOS installs get a tab strip; the new-tab button opens a new note.
  • Edge side panelIn Microsoft Edge this app can open docked beside the page you are reading, at 420 px.

Why some rows are “not available”

Capabilities differ by engine and operating system. Widgets are Windows-only, tabbed display is currently ChromeOS-only, and the share sheet exists on Android and ChromeOS. A “not available” row is information, not a failure.
