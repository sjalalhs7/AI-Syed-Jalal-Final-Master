    What this page really does

    • When available, the catalogue lists each tool with its description and source type. If a tool fails you see the failure message, not a substitute answer.
    • No cloud language model is called. Local tools include arithmetic, units, dates, hashes, contrast, CSV, JSON, diff and code audit. Time and generated IDs can change. Research calls the public Wikipedia API.
    • Where requests go. Requests are sent to the application server; research queries also go to Wikipedia. The app may save the prompt and trace in your account’s agent-run history. The agent exposes no shell, filesystem, eval or arbitrary-URL tool.
    • Task and note saves need confirmation. Toolbench can prepare a proposal but cannot confirm it; use JalalAi or JARVIS to prepare and confirm a save. Records, tasks and notes may be read.
    • Passing tools are not proof of correctness. The code audit is pattern matching, not a security review; the calculator is 64-bit floating point, not arbitrary precision.
