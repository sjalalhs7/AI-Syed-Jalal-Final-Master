    What this page really does

    • Every tool is listed above with its implementation. If a tool fails you see the failure message, not a substitute answer.
    • No model is called. Arithmetic, units, dates, hashes, contrast, CSV, JSON, diff and code audit are computed locally. Research calls the public Wikipedia API and nothing else.
    • Nothing leaves the app except the Wikipedia request. No filesystem, no shell, no eval, no arbitrary URL.
    • Read-only on your data. Records, tasks and notes are read; writes always need a separate explicit confirmation on their own page.
    • Passing tools are not proof of correctness. The code audit is pattern matching, not a security review; the calculator is 64-bit floating point, not arbitrary precision.
