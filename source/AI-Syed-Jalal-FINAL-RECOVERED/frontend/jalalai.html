Setup checklist

  1. Identify your operating system, RAM, graphics and free storage.
  2. Install OpenJarvis using its official instructions.
  3. Run jarvis doctor and check jarvis --help.
  4. Test the local model with “Who are you?”
  5. Configure ElevenLabs locally and test a voice.
  6. Connect Gmail/Calendar read-only; test each permission.
  7. Configure and test the 8:00 AM digest after backing up settings.

The setup cannot be marked complete until these tests run on your actual computer.
