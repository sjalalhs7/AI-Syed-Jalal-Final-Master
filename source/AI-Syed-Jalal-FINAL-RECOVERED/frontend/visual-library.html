Visual Library & Theme System

Choose a theme to apply it across the full page. The controls below are wired to the shared site theme controller.

Glassmorphism

Translucent layered surfaces, glass-like blur, cyan and violet edge lighting, cool dark background and readable contrast.

Applied to: page background, panels, cards, navigation, form controls and buttons.

Watermorphism

Deep ocean blues, aqua highlights, flowing layered gradients and cool luminous borders.

Applied to: the full page and supported interface surfaces, not a small preview tile.

Firemorphism

Charcoal, ember and volcanic reds with orange-gold highlights and warm ambient glow.

Applied to: the full page, navigation, cards, buttons, links and inputs.

Rainbowmorphism

Midnight violet with coordinated rainbow light accents. The approved SJ rainbow-and-crown logo remains unchanged.

Applied to: the full page and supported interface surfaces.
