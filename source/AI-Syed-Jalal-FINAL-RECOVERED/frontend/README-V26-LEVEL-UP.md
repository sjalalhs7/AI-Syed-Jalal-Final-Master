# AI-Syed Jalal V26 — Level Up

This package upgrades the V26 Mission Command Center into a more functional PC-first control surface while preserving the V25 visual baseline.

## Added
- GitHub Pages-safe internal navigation (no root `/dashboard` links).
- IndexedDB Data Vault for large local datasets.
- Region + Sector filtering.
- Add/Edit data workflow.
- JSON export and JSON/CSV import.
- Large-dataset rendering cap for responsive UI; storage is not limited to the visible rows.
- A4 Police Verification Print Studio.
- Print scale and margin controls.
- Browser print preview / print CSS.
- Dark/light theme from V26.
- Command palette and mission-control UI from V26.
- GitHub Actions Pages deployment workflow.
- `.nojekyll` for static deployment.

## Important
This is a V26 Level-Up package, not a claim that every legacy V25 application feature has been regression-tested. Keep the V25 archive as the rollback baseline.

GitHub Pages project sites are served under `/<repository>/`, so project-safe relative/fragment navigation is important. GitHub documents the project-site URL structure and publishing workflow.
