# Al-Syed Jalal AI V30 — Full-Stack Foundation

V30 is the next architectural stage after V29. It keeps the complete Mission Command Center frontend and adds a dependency-free Node.js backend foundation for real login, roles, centralized records, and server audit.

## Contents

- `frontend/` — GitHub Pages-ready static application
- `backend/` — Node.js API foundation
- `docs/` — architecture notes

## Important

GitHub Pages can host the frontend, but it does not execute server-side Node/PHP/Python. The backend must run on a server/container/host separate from GitHub Pages. GitHub documents Pages as static hosting and supports Actions for deployment.

The frontend's existing local Data Vault remains available as a fallback/demo workspace. Connecting the UI's Data Vault directly to the API is the next integration task after deploying the API endpoint.
